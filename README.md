# Учебный центр ИКЦ — прототип новой главной (v2)

Прототип главной страницы по новой структуре: каталог с картинками и вкладками по виду обучения, ближайшие группы и цены, шаги обучения, форматы, блок для организаций, документы, отзывы, новости.

Переключатель стилей A / B / C в левом нижнем углу. Жёлтым отмечены данные, которые заполняет учебный центр. Страница закрыта от индексации.
